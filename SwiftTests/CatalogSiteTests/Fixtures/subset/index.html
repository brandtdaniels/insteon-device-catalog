A command set value or profile entry with no mark is documented. The command set column counts only values that carry a mark. The identities column counts every identity. An identity with no mark is counted as documented: it is read from the documents the profile cites, not confirmed on a device.

How this catalog is built and how to help

Every fact comes from a public Insteon document, cited by its exact title and version in the profile's sources, or from an observation on a real device, which names the firmware it was seen on. A value that no document states, that documents disagree on, or that a device has shown carries a status (inferred, conflicting or observed) and a note that say so. A value with no mark is documented: a public Insteon document gives it.

Help is welcome wherever a value is marked inferred or conflicting, and for devices the catalog has no command set for:

  • Found a wrong or missing value? Open an issue that names the product, the value and the document or device that shows it.
  • Own a device? A pull request can record what it did: the model, the firmware it was running and what you saw. Adding or changing a profile describes the steps and the checks every change passes.
  • Writing software? API.md describes the files and how to read them.
